# خدماتي — iPhone وAndroid

مشروعا هاتف مبنيان بـ Capacitor 8.5.1 على واجهة الإصدار 1.3.1 الحالية. هذه حزمة اختبار وتجهيز للإطلاق، وليست إصدارًا معتمدًا في المتجرين. الخادم وبيانات الإنتاج لم يتغيرا.

## البناء

تحتاج Node.js 22 أو أحدث. Android يحتاج JDK 21 وAndroid SDK 36؛ iOS يحتاج macOS وXcode 26 أو أحدث.

من جذر المستودع:

```bash
npm ci --prefix mobile
npm run sync --prefix mobile
npm test --prefix mobile
```

ثم Android:

```bash
cd mobile/android
./gradlew assembleDebug bundleRelease lintDebug
```

ينتج APK بتوقيع التطوير للتجربة، وAAB غير موقّع. ملف AAB يحتاج توقيع رفع يملكه صاحب التطبيق قبل Play Console. معرّف APK التجريبي `om.khadamati.app.internal`، والمعرّف المقترح للإصدار `om.khadamati.app`؛ لم يُحجز أو يُعتمد في أي حساب متجر.

على Mac:

```bash
cd mobile
npx cap open ios
```

اختر فريق المطور في Xcode بعد اعتماد المعرّف. ثم اختبر على iPhone فعلي، وأنشئ Archive للإصدار، وارفعه إلى TestFlight. مخرجات CI الحالية للمحاكي فقط، ولا يمكن تثبيتها على iPhone أو رفعها كـ IPA.

سير العمل [mobile-build.yml](../.github/workflows/mobile-build.yml) يبني Android وiOS ويختبر ربط الواجهة. لا يتصل بحساب متجر ولا ينشر تلقائيًا. تحفظ المخرجات 14 يومًا ويمكن إعادة بنائها من الالتزام نفسه.

## الاتصال بالخادم

العنوان الافتراضي `https://khadamati-app-api.onrender.com`. لربط خادم تجريبي تملكه، مرّر عنوان HTTPS عامًّا وقت البناء:

```bash
KHADAMATI_MOBILE_API_BASE=https://your-staging-api.example npm run sync --prefix mobile
```

استبدل المثال بعنوان حقيقي قبل التنفيذ. العنوان يضمّن داخل النسخة؛ ليس سرًا. يمنع البناء أسماء المستخدمين وكلمات المرور والرموز في العنوان. لا يتضمن التطبيق قاعدة بيانات الخادم أو ملف البيئة أو ملفات الرفع الخاصة.

يستخدم `CapacitorHttp` للطلبات الأصلية وإدارة اتصال الجلسة. يلزم اختبار تسجيل الدخول، استرجاع الجلسة بعد الإغلاق، الخروج، حذف الحساب ورفع الملفات على جهازين فعليين قبل النشر، والتحقق أن الخادم المنشور يطابق فرع الإطلاق المختبر. اختبارات محاكاة الجسر لا تختبر مخزن كوكيز الهاتف أو نوافذ أذونات النظام.

## الوظائف المضافة

- تشغيل الواجهة والوسائط العامة من داخل حزمة التطبيق؛ لا يوجد `server.url` لتحميل موقع بعيد مكان التطبيق.
- تحديد الموقع عند الطلب، وإيقاف متابعة الخريطة والتسجيل الصوتي عند انتقال التطبيق للخلفية.
- مشاركة الاتفاقيات والتقويم والملفات عبر قائمة المشاركة الأصلية، وفتح روابط HTTPS الخارجية في متصفح النظام.
- تبقى ملفات المشاركة مؤقتًا في ذاكرة التطبيق الخاصة حتى تنتهي منها التطبيقات المستقبلة؛ تنظف المجلدات الأقدم من 24 ساعة عند التشغيل التالي.
- زر رجوع Android يغلق النافذة أو يرجع للصفحة الرئيسية قبل تصغير التطبيق.
- عدم تشغيل عامل تحديث PWA داخل نسخ المتاجر، مع الحفاظ على عمله في الويب.
- إعداد أذونات الكاميرا والصوت والموقع، وبيان أسباب الوصول إلى الملفات في iOS، ومنع نسخ بيانات Android المحلية احتياطيًا.
- توليد مقاسات الأيقونات من شعار خدماتي الموجود. صورة iOS ذات 1024 بكسل مشتقة من أصل 512؛ يفضّل توفير الأصل عالي الدقة قبل قائمة المتجر.

## ما لم يكتمل

- APNs/FCM غير مربوطين. الإشعارات داخل التطبيق تعمل حسب مساراته الحالية، وتوضح شاشة الإعدادات أن إشعارات الهاتف غير مفعلة في نسخة الاختبار.
- مشتريات المتاجر غير مدمجة. اشتراكات صلاحيات المزودين وإبراز المحتوى تحتاج قرار الإطلاق ونموذج دفع متوافقًا قبل التقديم؛ لا يُدّعى أن دفع الخدمة المنزلية يغطي هذه المشتريات الرقمية.
- لا توجد مفاتيح توقيع، ملفات provisioning، Firebase، حسابات مراجعة حقيقية أو بيانات اعتماد متجر في المستودع.
- ملف PrivacyInfo يحدد سبب استخدام واجهات الملفات فقط؛ لا يحل محل App Privacy أو Data safety أو سياسة الخصوصية المعتمدة.

لا تحفظ مفاتيح التوقيع في Git. استعمل Keychain أو أسرار بيئة إصدار مقيدة، وبعد إنشاء الحسابات أعطِ صلاحية مناسبة بدل مشاركة كلمة مرور الحساب.

## ملاحظات الاعتماديات

`sharp` أداة بناء فقط لإنتاج الأيقونات. ثُبتت النسخة 0.35.4 لمعالجة نتائج التدقيق الأمني. يثبت override محدود لـ `xcode → uuid` النسخة 11.1.1 المتوافقة مع CommonJS؛ فُحص تحليل مشروع Xcode وتوليد معرّفاته، لأن اعتماد CLI الافتراضي كان يجلب نسخة قديمة من uuid.
