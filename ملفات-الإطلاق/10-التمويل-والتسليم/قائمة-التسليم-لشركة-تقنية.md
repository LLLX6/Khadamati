# قائمة التسليم لشركة تقنية

## ما يمكن تسليمه

- وصول GitHub محدود إلى مستودع/فريق محدد.
- فرع وPull Request بدل الكتابة المباشرة على `main`.
- README و`AGENTS.md` وملفات الإطلاق.
- أسماء متغيرات البيئة دون قيم.
- حسابات اختبار غير حقيقية.
- مخطط قاعدة البيانات ونسخة بيانات مصطنعة.
- Runbooks للنشر والنسخ والاستعادة والتراجع.
- تقارير الأخطاء والاختبارات.
- مواصفات الخدمة وقرارات المنتج.

## ما لا يُسلّم كملكية

- ملكية GitHub أو المؤسسة.
- ملكية النطاق أو البريد الرئيسي.
- ملكية Render أو قاعدة البيانات أو التخزين.
- Apple Developer أو Google Play Console.
- بوابة الدفع والحساب البنكي.
- كلمات المرور وOTP ورموز الاسترداد.
- البطاقة البنكية أو الهوية خارج قناة التحقق الرسمية.

## عند انتهاء العقد

- إلغاء وصول الموظفين والمفاتيح.
- تغيير الأسرار المشتركة.
- استلام كل PR والوثائق والأصول.
- تأكيد حذف النسخ المحلية للبيانات.
- تشغيل اختبار بناء واستعادة بحضور الطرفين.
- توثيق آخر إصدار وديون التقنية المفتوحة.
