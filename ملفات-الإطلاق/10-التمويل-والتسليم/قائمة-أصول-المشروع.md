# قائمة أصول المشروع

## تقنية

- مستودع GitHub وتاريخ Git.
- الواجهة PWA وملفات `public`.
- خادم Python وطبقة المجال.
- مخطط SQLite وأدوات التدقيق والنسخ والاستعادة.
- اختبارات الوحدة وAPI والواجهة والأداء.
- GitHub Actions Quality Gate.
- إعداد Render Blueprint.

## منتج

- الأقسام والخدمات والمطابقة.
- الطلبات والعروض والمحادثات والإشعارات.
- حسابات المستخدم والمزود والشركة والإدارة.
- الاشتراكات والباقات وموافقات التواصل.
- الخرائط والإرشادات الثنائية اللغة.

## ملكية وهوية

- اسم «خدماتي» و`Khadamati App`.
- الشعار والأيقونات والصور.
- السياسات ومسودات المتاجر والتسليم.
- اسم النطاق والحسابات: `[غير مثبتة داخل المستودع]`.

## ما لا يدخل في Git

- الأسرار، قواعد البيانات الفعلية، Uploads، Backups، Logs، شهادات التوقيع،
  حسابات المتاجر، بيانات البنك، OTP، ورموز الاسترداد.
