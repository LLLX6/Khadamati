# البنية التقنية المختصرة

```text
Browser/PWA
  ├─ GitHub Pages: HTML/CSS/JavaScript + Service Worker
  └─ HTTPS API
       └─ Python ThreadingHTTPServer
            ├─ SQLite
            ├─ Local uploads
            └─ Optional Web Push / WhatsApp adapters
```

## مصدر الحقيقة

الخادم وقاعدة البيانات مصدر الحقيقة للبيانات الخاصة. `localStorage` يحتفظ
بحالة واجهة وجلسة، ولا ينبغي استخدامه قاعدة متعددة المستخدمين.

## حدود الإنتاج

- SQLite مناسب للمرحلة المحلية/المحدودة لكنه يحتاج قرصًا دائمًا وقياس
  تزامن أو انتقالًا مخططًا إلى PostgreSQL.
- Uploads المحلية تحتاج تخزينًا دائمًا أو كائنات.
- الخادم الحالي دون إطار ويب أو ORM؛ أي انتقال يحتاج قرارًا واختبارات، لا
  استبدالًا سريعًا.

التفاصيل في `02-قاعدة-البيانات-والنسخ-الاحتياطي.md` و
`05-دليل-الخادم-والنشر.md`.
