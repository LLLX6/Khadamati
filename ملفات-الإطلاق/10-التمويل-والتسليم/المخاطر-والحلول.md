# المخاطر والحلول

| الخطر | التأثير | الإجراء |
|---|---|---|
| SQLite وUploads على قرص Render غير مثبت | فقد البيانات | قرص دائم مؤقتًا أو PostgreSQL وتخزين كائنات بعد موافقة |
| لا Backup خارجي مجدول | فقد شامل | وجهة مملوكة واختبار استعادة |
| Token في localStorage | زيادة أثر XSS | جلسات HttpOnly ضمن تغيير معماري مخطط |
| CSP تحتوي `unsafe-inline` | XSS | فصل JS/CSS تدريجيًا واختبار كامل |
| لا مراجعة اختراق بشرية | ثغرات غير مكتشفة | اختبار مستقل قبل العامة |
| بلاطات OSM العامة | توقف/مخالفة حمل | مزود خرائط متوافق عند قياس الحمل |
| لا تطبيق أصلي | فجوة متاجر | قرار Capacitor/تقنية مناسبة بعد دراسة |
| ملكية الصور غير مثبتة | مطالبة حقوق | سجل منشأ وعقود |
| متطلبات قانونية غير معتمدة | رفض/مسؤولية | مستشار عُماني وجهات رسمية |
| لا مراقبة خارجية | تأخر اكتشاف العطل | خدمة مراقبة مملوكة بعد موافقة التكلفة |

المخاطر لا تختفي بالتوثيق؛ يجب إغلاقها واختبار الإغلاق قبل الإنتاج.
