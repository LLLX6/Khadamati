# ألوان العلامة

القيم التالية مستخرجة من متغيرات CSS الحالية وليست إعادة تصميم:

| الاستخدام | القيمة |
|---|---|
| الخلفية | `#F4F6FB` |
| النص الداكن | `#172033` |
| الأزرق الأساسي | `#102A43` |
| الأزرق الثانوي | `#1F5F8B` |
| الفيروزي | `#15A085` |
| الذهبي | `#D8B46A` |
| الخطأ/الخطر | `#D84B4B` |
| النجاح | `#169B62` |

## قواعد

- تحقق من تباين WCAG للنصوص الصغيرة قبل اعتماد أي تركيب.
- لا تستخدم الفيروزي الفاتح للنص فوق الأبيض دون فحص.
- الأحمر للحالات الحرجة وليس للزينة.
- الذهبي لهوية مميزة أو اشتراك، لا لنصوص طويلة.
- الوضع الداكن يحتاج قيمًا دلالية مستقلة، لا عكسًا آليًا للألوان.
