# قائمة متطلبات الحساب البنكي التجاري

تختلف المتطلبات حسب البنك والشكل القانوني، لذلك هذه قائمة أسئلة وتجهيز لا
قائمة قبول نهائية.

- [ ] السجل التجاري الساري.
- [ ] مستندات المفوضين بالتوقيع.
- [ ] الهوية والعنوان وبيانات التواصل.
- [ ] عقد التأسيس أو النظام الأساسي إن انطبق.
- [ ] إثبات المستفيد الحقيقي إن طُلب.
- [ ] وصف النشاط ومصدر الأموال المتوقع.
- [ ] نموذج الإيرادات والاشتراكات.
- [ ] رابط تجريبي وسياسات الخصوصية والإلغاء.
- [ ] تقدير حجم المعاملات: `[لا يُخترع؛ يملؤه المالك]`.
- [ ] العملات والقنوات المطلوبة.
- [ ] صلاحيات المستخدمين والتنبيهات وحدود التحويل.

## ضوابط الملكية

- الحساب باسم الكيان وليس باسم الشركة التقنية المنفذة.
- البريد والهاتف والمصادقة المتعددة تحت سيطرة المالك أو المفوض.
- لا ترسل رمز OTP أو بيانات البطاقة للمطور.
- امنح وصولًا محاسبيًا محدودًا عند الحاجة.

كل قائمة رسمية ورسوم وشروط يجب أخذها من البنك المختار مباشرة.
