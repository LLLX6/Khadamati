# قائمة موافقات حماية البيانات

**هذه قائمة امتثال أولية وليست رأيًا قانونيًا.**

## البيانات الفعلية في التطبيق

- الهاتف وبيانات الحساب.
- الموقع الذي يختاره المستخدم أو يمنح إذنًا لاستخدامه.
- الصور والمرفقات ووثائق المزود.
- الطلبات والمحادثات والرسائل الصوتية والإشعارات.
- بيانات الاشتراك والمدفوعات الوصفية دون بيانات البطاقة.

## المطلوب قبل الإطلاق

- [ ] تحديد الكيان المتحكم بالبيانات وعنوانه.
- [ ] تحديد أغراض وأساس معالجة كل فئة.
- [ ] اعتماد سياسة الخصوصية بالعربية والإنجليزية.
- [ ] حفظ موافقة المستخدم على إصدار السياسة.
- [ ] مسار لسحب الموافقة عند انطباقه.
- [ ] مسار حذف الحساب والبيانات.
- [ ] سياسة احتفاظ معتمدة.
- [ ] عقود مع المعالجين الخارجيين.
- [ ] تقييم نقل البيانات خارج عُمان.
- [ ] إجراءات حقوق أصحاب البيانات والشكاوى.
- [ ] خطة حادث وتسريب بيانات.
- [ ] تحديد ما إذا كان يلزم مسؤول حماية بيانات أو إخطار/تصريح رسمي.
