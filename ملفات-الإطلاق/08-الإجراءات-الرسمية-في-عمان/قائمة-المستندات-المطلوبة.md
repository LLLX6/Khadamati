# قائمة المستندات المطلوبة

## ملكية وهوية

- [ ] هوية المالك والمفوضين.
- [ ] السجل التجاري وعقد التأسيس عند انطباقه.
- [ ] مستند المستفيد الحقيقي.
- [ ] العنوان وإثباته.
- [ ] تفويضات التوقيع.

## المنتج

- [ ] وصف النشاط والمنصة.
- [ ] نموذج الإيرادات دون أرقام مختلقة.
- [ ] سياسة الخصوصية والشروط والحذف والإلغاء.
- [ ] مخطط البيانات والأمان.
- [ ] رابط Staging وحسابات اختبار غير حقيقية.
- [ ] دليل ملكية الاسم والشعار والصور والكود.

## البنك والدفع

- [ ] خطاب/قرار فتح الحساب.
- [ ] توقعات معاملات يملؤها المالك.
- [ ] سياسات الاسترداد والشكاوى.
- [ ] عقد مزود الدفع.
- [ ] مستندات التحقق المطلوبة من المزود.

## المتاجر

- [ ] حسابات مطور باسم المالك أو المؤسسة.
- [ ] بيانات التطبيق والأيقونات والصور.
- [ ] رابط خصوصية ودعم وحذف حساب عام.
- [ ] شهادات وتوقيع تحفظ خارج Git.

القائمة النهائية تؤخذ من كل جهة وقت التقديم.
