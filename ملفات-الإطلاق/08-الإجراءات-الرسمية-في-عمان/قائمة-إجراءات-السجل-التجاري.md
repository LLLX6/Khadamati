# قائمة إجراءات السجل التجاري

**هذه قائمة تحضير، وليست ضمانًا لقبول الطلب.**

## قبل البدء

- [ ] تحديد الشكل القانوني والمالك والمفوضين.
- [ ] التحقق من الاسم التجاري وتوفره.
- [ ] مراجعة وصف النشاط والأنشطة المطلوبة مع مكتب سند.
- [ ] تحديد العنوان وبيانات التواصل الرسمية.
- [ ] التحقق من الحاجة إلى موافقات قطاعية إضافية.
- [ ] تجهيز الهوية والمستندات المطلوبة من الجهة.

## أثناء الإجراء

- [ ] استخدام منصة أو قناة حكومية رسمية.
- [ ] مراجعة كل نشاط قبل اعتماده.
- [ ] عدم إدخال بيانات أو دفع رسوم عبر روابط غير رسمية.
- [ ] حفظ رقم الطلب والإيصال والنسخة النهائية من السجل.

## بعد الإصدار

- [ ] حفظ السجل في مخزن مؤسسي مشفر.
- [ ] فتح البريد الرسمي والحساب البنكي باسم الكيان.
- [ ] مراجعة التسجيل الضريبي والتزامات حماية البيانات.
- [ ] تحديث السياسات باسم الكيان ورقمه وعنوانه قبل النشر.

مصادر تم التحقق منها في 26 يوليو 2026:

- [Gov.om: بدء نشاط تجاري](https://gov.om/en/w/starting-a-business)
- [Gov.om: تسجيل شركة الشخص الواحد](https://gov.om/w/apply-for-commercial-registration-for-one-person-company)
- [منصة عُمان للأعمال](https://tejarah.gov.om/)

الرسوم والمدد والوثائق الفعلية تحتاج تحققًا حديثًا عند تقديم الطلب.
