# جرد أصول الملكية الفكرية

| الأصل | مكانه | الحالة | الإجراء المطلوب |
|---|---|---|---|
| كود الواجهة والخادم | مستودع GitHub | محفوظ بإصدارات Git | إثبات المالك والمساهمين |
| اسم «خدماتي» | النصوص والبيانات الوصفية | مستخدم وغير مثبت التسجيل | بحث علامة رسمي |
| الشعار | ملفات PNG وSVG | المصدر موجود، سلسلة الملكية غير موثقة | عقد/إقرار المصمم |
| الصور الإرشادية والإعلانية | مجلدات الأصول | مصدر بعض الصور يحتاج توثيقًا | سجل مصدر وترخيص كل صورة |
| نصوص السياسات | `ملفات-الإطلاق/07-*` | مسودات مولدة للمشروع | مراجعة قانونية واعتماد |
| تصميم الواجهة | `index.html` و`public/index.html` | جزء من المشروع | توثيق المساهمات الخارجية |
| قاعدة البيانات والمخطط | `server.py` وتقارير البيانات | تصميم تقني للمشروع | حماية النسخ وعدم مشاركتها |
| اسم النطاق | غير مثبت في المستودع | `[يُستكمل لاحقًا]` | يبقى باسم المالك/المؤسسة |

## عناصر تحتاج دليلًا

- عقود أو إقرارات نقل حقوق المصممين والمطورين.
- فواتير أو تراخيص الصور والخطوط والأصوات.
- شروط استخدام خرائط OpenStreetMap ومزود البلاطات.
- سجل مساهمات أي شركة تقنية مستقبلية.

لا تسلم ملكية GitHub أو النطاق أو حسابات المتاجر أو الدفع للمقاول؛ امنحه
صلاحية محدودة قابلة للإلغاء.
