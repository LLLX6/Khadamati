# قائمة صور وأيقونات المتاجر

**تاريخ الجرد:** 26 يوليو 2026

## الأصول الحالية

| الأصل | المقاس | الملاحظة |
|---|---:|---|
| `app-icon-192.png` | 192×192 RGBA | PWA |
| `app-icon-512.png` | 512×512 RGBA | PWA ومرشح أولي لـGoogle Play |
| `apple-touch-icon.png` | 180×180 RGBA | Web Touch Icon |
| `logo.svg` | 512 ViewBox | مصدر متجهي موجود |
| صور الحملات | 1600×686 | عرض داخل التطبيق، وليست Screenshots متجر |
| صور الإرشاد | 960×960 | إرشادات مربعة داخل التطبيق |
| صور المزودين | 900×900 | بيانات عرض، لا تستخدم كدليل مستخدم حقيقي |

يوجد Mirror مقصود داخل `public/` لملفات GitHub Pages؛ ليس نسخة ملكية مستقلة.

## Apple

- App Icon ينشأ داخل Asset Catalog بعد إنشاء مشروع iOS.
- Screenshots من تشغيل حقيقي، من 1 إلى 10 لكل مقاس وفق صفحة Apple.
- المصدر الحالي يذكر لمجموعة iPhone 6.9 بوصة مقاسات مقبولة منها:
  `1260×2736` أو `1290×2796` أو `1320×2868` عموديًا.
- الصور لا تحتوي Alpha وفق مواصفات Screenshots.
- نحتاج مجموعة عربية ومجموعة إنجليزية.
- لا نضع إطار هاتف أو نصًا يخفي UI إلا بعد التحقق من سياسة metadata.

## Google Play

- App Icon: 512×512، PNG 32-bit، Alpha مسموح، وحجم أقصى 1024KB حسب
  المصدر الرسمي الحالي.
- Feature Graphic مطلوبة؛ تُنشأ بعد اعتماد رسالة العلامة.
- Screenshots حقيقية للهاتف بالعربية والإنجليزية.
- لا تستخدم صورًا تجريبية توحي بمستخدمين أو تقييمات حقيقية.

## قائمة اللقطات المقترحة

1. البداية واختيار الدور.
2. الطلب المباشر: القسم والخدمة.
3. اختيار الموقع.
4. نتائج المطابقة وبطاقات المزود.
5. العرض والمقارنة.
6. المحادثة وحالة المهمة.
7. ساحة الطلبات للمزود.
8. ملف المزود والخدمات.

## نواقص

- 🔴 لا توجد Screenshots متجر نهائية؛ لا يوجد تطبيق أصلي بعد.
- 🔴 لا توجد Feature Graphic معتمدة.
- 🟡 الأيقونة 512 موجودة، لكن يجب اختبار Safe Zone وMask على Android.
- 🟡 يحتاج الشعار مراجعة مصمم ومالك العلامة قبل التسجيل الرسمي.
