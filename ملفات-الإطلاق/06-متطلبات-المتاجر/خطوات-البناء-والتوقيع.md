# خطوات البناء والتوقيع

## الوضع الحالي

- PWA ثابتة مع خادم Python.
- لا يوجد Flutter أو React Native أو Capacitor أو مشروع Native.
- لا يوجد `ios/` أو `android/`.
- لا يوجد Bundle ID أو Package Name مسجل.
- لا توجد شهادات أو مفاتيح توقيع.

لذلك لا توجد أوامر Build أصلية يمكن تشغيلها الآن.

## قرار تقني مطلوب

يُختار بعد Proof of Concept على staging:

1. **غلاف أصلي خفيف** إذا كانت وظائف الكاميرا والميكروفون والموقع وPush
   والمرفقات تعمل بثبات، مع Navigation وأزرار الرجوع الأصلية.
2. **تطبيق أصلي/هجين أعمق** إذا احتاج المنتج Background Push أو Offline أو
   تكاملات أصلية يصعب ضمانها داخل WebView.

لا يُعتمد الخيار على سرعة التطوير فقط؛ يجب قياس الأمان وتجربة iOS وAndroid
وإمكانية الصيانة.

## iOS بعد اعتماد القرار

1. إنشاء المشروع على Mac داخل حساب المؤسسة.
2. ضبط Bundle ID المعتمد.
3. إضافة Usage Descriptions للصلاحيات اللازمة فقط.
4. تقييد Navigation إلى نطاقات التطبيق الموثوقة.
5. منع فتح صفحات غير موثوقة داخل WebView.
6. إعداد Universal Links عند امتلاك نطاق.
7. اختبار الموقع والكاميرا والميكروفون والتحميل والإشعارات.
8. Archive وValidate في Xcode.
9. رفع إلى TestFlight فقط أولًا.
10. حفظ الشهادات وصلاحيات الحساب لدى المالك.

## Android بعد اعتماد القرار

1. إنشاء مشروع Android.
2. ضبط Package Name المعتمد وTarget API الحالي.
3. إضافة الصلاحيات اللازمة فقط.
4. تقييد WebView وFile Access وMixed Content.
5. إعداد App Links عند امتلاك نطاق.
6. إنشاء Upload Key في حساب/جهاز المالك وحفظ نسخة مشفرة.
7. بناء `.aab` Release.
8. تفعيل Play App Signing من حساب المالك.
9. رفع إلى Internal Testing أولًا.
10. اختبار Crash/ANR وسياسات البيانات قبل أي مسار عام.

## الأسرار والملكية

- لا يُحفظ Keystore أو Certificate أو Provisioning Profile في Git.
- لا ترسل Recovery Codes لشركة التطوير.
- حسابا Apple وGoogle، مفاتيح التوقيع، الدومين، والخادم تبقى ملكًا للمالك أو
  المؤسسة.
- تمنح الشركة أدوارًا محدودة قابلة للإلغاء.

## بوابات القبول قبل التوقيع

- CI ناجح.
- بيئة staging مستقرة.
- Backup وRestore مختبران.
- سياسات وروابط عامة معتمدة.
- حسابات مراجعة.
- اختبار جهاز iPhone وAndroid فعلي.
- لا أسرار أو بيانات حقيقية داخل Build.
- نسخة Release ترتبط بخادم HTTPS معتمد فقط.
