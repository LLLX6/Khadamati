# سياسة الدفع

> **هذه الوثيقة مسودة تحتاج مراجعة قانونية واعتمادًا رسميًا قبل النشر.**

## النموذج الحالي

- المستخدم العادي لا يدفع رسوم منصة.
- الاشتراكات والترقيات والترويج مخصصة للمزودين والشركات.
- العملة: الريال العُماني `OMR`.
- بوابة الدفع الإنتاجية غير مختارة وغير مفعلة.
- أي طلب حالي يبقى «بانتظار الدفع» أو «بانتظار موافقة الإدارة» ولا يعرض نجاحًا
  وهميًا.

## التحقق

- السعر والمدة والخطة مصدرها الخادم، لا قيمة الواجهة.
- لا تفعّل الخطة إلا بعد Webhook صحيح أو موافقة إدارية موثقة.
- لا تخزن المنصة رقم البطاقة أو CVV.
- لكل دفعة مرجع وحالة وسجل تدقيق.
- يرفض اختلاف المبلغ أو العملة أو الخطة.

## الفواتير والضرائب

بيانات الفاتورة والضريبة والرقم الضريبي تُستكمل بعد إنشاء الكيان ومراجعة
المحاسب. لا تُظهر المنصة فاتورة ضريبية قبل توفر متطلباتها.

## المدفوعات اليدوية أو المجانية

يجوز للإدارة منح باقة مكافأة دون دفعة إذا سجلت:

- سبب المنح.
- المدة والخطة.
- المسؤول الذي اعتمدها.
- وقت الاعتماد.
- أنها مجانية/ترويجية وليست دفعة.
