# سياسة الاحتفاظ بالبيانات

> **هذه الوثيقة مسودة تحتاج مراجعة قانونية واعتمادًا رسميًا قبل النشر.**

الأرقام التالية **مقترحات تشغيلية** وليست مددًا معتمدة:

| الفئة | المقترح | سبب الحفظ | الإجراء |
|---|---|---|---|
| حساب نشط | مدة النشاط | تقديم الخدمة | حذف/تعطيل عند الطلب |
| طلب مغلق ومحادثته | 24 شهرًا | نزاعات وجودة | إخفاء الهوية أو حذف بعد المدة |
| موقع دقيق | مدة الطلب + 90 يومًا | التنفيذ والنزاع | تقليل الدقة أو الحذف |
| صور مشكلة | مدة الطلب + 12 شهرًا | جودة وشكاوى | حذف عند انتهاء الحاجة |
| وثائق مزود | مدة الحساب + 90 يومًا | تحقق ومراجعة | حذف آمن ما لم يوجد التزام |
| موافقة سياسة/تواصل | مدة الحساب + مدة إثبات مطلوبة | إثبات الموافقة | تقييد الوصول |
| سجل أمني | 90 إلى 180 يومًا | اكتشاف إساءة | تدوير وحذف |
| شكوى مفتوحة | حتى الإغلاق + 24 شهرًا | دفاع ومراجعة | تقييد ثم حذف |
| سجلات مالية/فواتير | `[مدة المحاسب والقانون]` | التزام مالي | أرشفة مقيدة |
| Backup | 30 إلى 90 يومًا | تعافٍ كارثي | تشفير ودوران |

قبل الاعتماد:

1. يراجع محامٍ قانون حماية البيانات.
2. يراجع محاسب مدد السجلات المالية.
3. تُضبط Jobs الحذف فعليًا.
4. يُختبر حذف نسخة واستعادة Backup مع إعادة تطبيق طلبات الحذف.
5. لا تحتفظ المنصة «إلى الأبد» افتراضيًا.
