# جدول الأطراف الخارجية

|---|---|---|---|---|
| GitHub Pages | مستخدم للواجهة الحالية | استضافة PWA | IP وطلبات ملفات وفق سياسة GitHub | تقييم ملاءمة الإنتاج والنطاق |
| Render | مستخدم للخادم الحالي | API وقاعدة/ملفات حاليًا | بيانات التطبيق الكاملة بحسب المسار | إثبات المنطقة والديمومة والعقد |
| OpenStreetMap/OSMF | مستخدم للخرائط | Tiles | IP وReferer وموضع الخريطة المرئي | مزود خرائط إنتاجي وسياسة الاستخدام |
| Apple | مستقبلي | توزيع iOS | بيانات حساب المتجر وتشخيصات حسب SDK | حساب المالك واتفاقياته |

1. تقييم البيانات المرسلة.
2. التحقق من الشروط والترخيص.
3. تحديد المنطقة والاحتفاظ.
4. تحديث سياسة الخصوصية ونماذج المتاجر.
