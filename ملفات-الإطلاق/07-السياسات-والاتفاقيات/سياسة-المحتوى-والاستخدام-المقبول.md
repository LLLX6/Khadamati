# سياسة المحتوى والاستخدام المقبول

> **هذه الوثيقة مسودة تحتاج مراجعة قانونية واعتمادًا رسميًا قبل النشر.**

## مسموح

- طلب خدمة مشروع وواضح.
- صور لازمة لشرح المشكلة.
- أعمال يملك المزود حق عرضها.
- تقييم صادق مرتبط بتجربة.
- عرض مهني ضمن الخدمة المسجلة.

## ممنوع

- الاحتيال أو انتحال الهوية.
- التهديد أو التحرش أو خطاب الكراهية.
- المحتوى الجنسي أو استغلال الأطفال.
- نشر بيانات شخصية أو وثائق شخص آخر.
- برمجيات أو ملفات ضارة.
- خدمات أو بضائع غير قانونية.
- تقييمات مزيفة أو تلاعب بالترتيب.
- Spam وترشيحات أو عروض متكررة.
- جمع أرقام العملاء أو بيعها.
- محاولة تجاوز الصلاحيات أو حدود الباقة.

## الإجراء

قد يُخفى المحتوى أو يوقف الحساب أو تحفظ الأدلة أو يحال البلاغ إلى جهة مختصة
بحسب الخطورة. القرارات المهمة تسجل ويمكن طلب مراجعتها عبر الدعم.
