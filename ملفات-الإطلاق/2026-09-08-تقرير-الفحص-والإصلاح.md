## الملفات المعدلة

- `khadamati_security.py`: معالجة الأرقام المحلية واستهلاك رموز الاسترداد.
- `server.py`: إعادة محاولة إشعارات الجهاز بعد تعطل DNS المؤقت.
- `scripts/restore_sqlite_backup.py`: التحقق من سلامة الأرشيف قبل استعادته.
- `tests/test_security_2fa.py` و`tests/test_backup_restore.py`: اختبارات تمنع عودة الأخطاء المثبتة.
- `tests/test_push_delivery.py`: اختبارات سلوك تسليم الإشعارات.
- `tests/security-api.py`: إصلاح طريقة اختبار الرفض المبكر للطلبات الكبيرة.
- هذا التقرير.

- تعذر تنزيل Chromium محليًا لأن سياسة شبكة بيئة العمل حجبت نطاق التنزيل. أُنجزت اختبارات الترجمة المرئية وواجهة الهاتف بنجاح على متصفح Chromium في GitHub Actions. اختبارات الواجهة تستخدم محاكاة API الموجودة في المشروع، بينما اختبارات API تشغّل الخادم الفعلي بقواعد مؤقتة.
- لم ينجح جلب صفحات التطبيق العامة عبر أداة الويب؛ ذلك قيد وصول من هذه البيئة ولا يثبت توقف التطبيق.
