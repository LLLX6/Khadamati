# إعادة تصميم الدخول والمجتمع

**الفرع:** `release/khadamati-entry-community-redesign`

**نطاق العمل:** البداية، دخول وتسجيل المستخدم، دخول وتسجيل المزود، المجتمع، ساحة الطلبات، الباقات، وتحكم الإدارة.

## النتيجة

تم تحويل مناطق الدخول والتسجيل والمجتمع من شاشات متفرقة وكثيفة إلى مسارات واضحة ومترابطة، مع الحفاظ على واجهات الخادم والبيانات القديمة. لم تُحذف حسابات أو طلبات أو محادثات أو باقات، ولم تُنفذ عملية ترحيل هدامة.

## ما نُفذ

### البداية والدخول

- صفحة بداية مركزة بخيارَي المستخدم والمزود، مع دخول الزائر وتبديل اللغة.
- دخول المستخدم داخل واجهة مختصرة تحتوي الهاتف ورمز الدخول والإجراءات الضرورية فقط.
- فصل إنشاء حساب المستخدم عن تسجيل الدخول، وتقسيمه إلى ثلاث مراحل: الأساسيات، الملف، الحماية.
- بوابة أعمال مستقلة للمزود تعرض الدخول وإنشاء الحساب بوضوح.
- تقسيم تسجيل المزود إلى الحساب، الخدمات، والثقة، مع اختيار متجاور بين الفرد والشركة.
- الحفاظ على إيماءة الإدارة الداخلية الحالية من دون إظهارها أو كسرها.

### المجتمع وساحة الطلبات

- أصبح المجتمع صفحة كاملة بقسمين فقط: `الباقات` و`ساحة الطلبات`.
- دمج المنشورات القديمة والطلبات المركزية في قائمة موحدة بدل تكرار «أبحث عن» و«الفرص الحالية».
- نقل الأقسام والنطاق والمنطقة والترتيب إلى درج بحث وفلاتر واحد.
- يرى المزود الطلبات المطابقة ويستطيع إرسال عرض أو فتح المحادثة وفق حالة الطلب.
- يرى المستخدم الطلبات العامة ويستطيع إدارة طلبه أو ترشيح مزود لطلب مستخدم آخر.
- زر الإضافة للمستخدم ينشئ طلبًا مركزيًا حقيقيًا، وزر المزود داخل الباقات يفتح محرر الباقة.
- حافظت الطلبات القديمة على الظهور من دون إنشاء مصدر بيانات موازٍ.

### الإدارة

- مركز قرار للمجتمع يعرض المؤشرات، ما يحتاج إجراءً، الباقات، ساحة الطلبات، البلاغات والإعدادات.
- مفاتيح مستقلة لتشغيل المجتمع والباقات وساحة الطلبات وعروض المزودين وترشيحات المستخدمين والمراجعة المسبقة.
- الإعدادات محفوظة في الخادم، وتُطبق على إنشاء الباقات والطلبات والعروض بدل إخفاء الأزرار بصريًا فقط.
- بطاقات الطلب الإداري تحتفظ بإجراءات الإدارة الخاصة: المطابقات، الإيقاف، العاجل، الإغلاق والإدارة.

### الواجهة والتوافق

- نظام بصري موحد لمسارات الدخول والتسجيل والمجتمع والإدارة.
- حالات هاتفية مضبوطة من `320px` إلى `430px`، مع دعم سطح المكتب.
- دعم العربية والإنجليزية و`RTL/LTR` والوضعين الفاتح والداكن.
- تطابق كامل بين `index.html` و`public/index.html` وبين ملفي CSS المناظرين.

## نتائج التحقق

- فحص JavaScript المضمن: ناجح.
- `npm run check:js`: ناجح.
- تجميع Python للملفات المعدلة: ناجح.
- اختبارات المجتمع: `6/6` ناجحة.
- جميع اختبارات Python: `63/63` ناجحة.
- اختبار API المعزول: ناجح.
- اختبار الأمان: ناجح، ويشمل CORS وIDOR والملفات والجلسات وعزل البيانات.
- رحلة الواجهة الكاملة: المستخدم والطلب والمزود والإدارة ناجحة.
- الهاتف: `320x700` و`375x812` و`390x844` و`430x932` ناجحة.
- سطح المكتب: `1280x900` ناجح.
- لا توجد أخطاء Console مؤثرة في المسار المختبر.
- القياس المحلي: تحميل الصفحة و`DOMContentLoaded` خلال `72ms`، و`FCP` خلال `88ms`، والجاهزية التفاعلية خلال `1149ms`. هذه أرقام بيئة محلية وليست ضمانًا لأداء الإنتاج.
