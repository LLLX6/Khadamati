# سجل إصدار خدماتي v1.3.1 / r1

التاريخ: 25 أغسطس 2026 — توقيت مسقط

## نطاق التحديث

- استعادة 12 مزوداً تجريبياً قديماً و28 خدمة وصور العرض المرتبطة بها.
- لا تُضاف البيانات عند بدء الخادم تلقائياً؛ يلزم قرار صريح من مدير يملك
  صلاحية إدارة المزودين.
- جميع سجلات العرض موسومة في قاعدة البيانات والواجهة بأنها تجريبية.
- المزودون متاحون للبحث والمطابقة والطلب داخل التطبيق.
- أرقام الاتصال الخارجية للمزودين التجريبيين لا تظهر للمستخدم.
- يمكن إيقاف السجل ثم أرشفته ثم حذف هويته من لوحة الإدارة، مع بقاء أثر التدقيق.
- الإجراء متكرر النتيجة: تشغيله مرة أخرى يعيد تجهيز السجلات نفسها ولا يكررها.

## نتائج التحقق المحلي

- Python compile/compileall: نجح.
- اختبارات الوحدة: 172 من 172 نجحت.
- اختبار استعادة الكتالوج: 12 من 12 قابلون للطلب، وإجمالي الخدمات 28.
- اختبارات API المعزولة والأمان والثقة والمنصة: نجحت.
- اختبار واجهة هاتف 390×844: نجحت رحلات المستخدم والمزود والإدارة وملاءمة الشاشة.
- عقد اللغات: العربية والإنجليزية والهندية والبنغالية والأوردو نجحت.
- فحص JavaScript والمرايا والمستودع: نجح دون تحذيرات مستودع.
- npm audit: لا توجد ثغرات معروفة.
- اختبار API محلي منخفض الحمل: 120 طلباً، 0 أخطاء، p95 = 121.91ms.
- اختبار الواجهة المحلي: interactiveReady = 1620ms ضمن الهدف المحلي.

هذه نتائج محلية معزولة وليست وعداً بسعة إنتاجية أو اختبار تحميل آلاف العملاء.

التنزيل، ونشر الخدمة الحالية في Render. لا تُسجل هنا رموز إدارة أو أسرار أو
بيانات دخول.

## قيد Render المعروف

إعداد الإصدار يطلب خطة Starter وقرصاً دائماً واحداً على
`/var/data/khadamati`. إذا بقيت الخدمة على Free فلن تصبح `/readyz` جاهزة
للإنتاج، وقد تضيع بيانات SQLite والملفات بعد إعادة التشغيل أو إعادة النشر.
إضافة وسيلة الدفع واختيار الخطة إجراء يخص مالك الحساب ولا ينفذه هذا الإصدار.
