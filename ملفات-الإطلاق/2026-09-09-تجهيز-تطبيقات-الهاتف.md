## ما جرى تجهيزه

1. مشروعا Capacitor 8.5.1 مع تثبيت نسخ الاعتماديات وAndroid target API 36.
2. حزمة محلية للأصول العامة فقط، وإعداد عنوان API صالح للهاتف. أصلح شرطًا كان يعطل API تحت بروتوكول iOS المحلي.
3. الموقع، مشاركة الملفات، الروابط الخارجية، الرجوع في Android، والتحديث عند العودة للتطبيق.
4. تعطيل عامل PWA داخل الهاتف، وبيان صريح أن APNs/FCM غير مفعّلَين في نسخة الاختبار.
5. أذونات النظام، قواعد النسخ الاحتياطي في Android، وPrivacyInfo الخاص بسبب الوصول إلى توقيت الملفات في iOS.
6. توليد أيقونات الهاتف من شعار خدماتي الحالي، وسير عمل CI لبناء APK وAAB غير موقّع ونسخة iOS للمحاكي.
7. اختبارات لسلوك الجسر وتكامل الواجهة باللغات الخمس، وتوافق مشاركة الملفات مع WebView الأقدم والروابط مع الأصل المحلي غير القياسي.
8. إصلاح حذف بيانات ملف المستخدم: عند تأكيد الحذف بالرمز الصحيح يمسح الخادم البريد والعمر والجنسية والجنس والمحافظة والولاية إلى جانب الحقول السابقة، مع اختبار رفض الرمز الخاطئ وإبطال جلسة الحساب.

حافظ التعديل على ملفات الويب المتطابقة. لم يغيّر مخطط قاعدة البيانات أو إعدادات الخادم أو الأسعار، ولم يمس خادم أو بيانات الإنتاج. إصلاح الحذف يخص إجراء حذف يطلبه صاحب الحساب ويؤكده، ولا يغير الحسابات النشطة.

رسوم Apple المعلنة 99 دولارًا سنويًا (قد تختلف العملة محليًا)، وGoogle Play ‏25 دولارًا مرة واحدة. لم تُشترَ أي عضوية ولم يُغيّر أي اشتراك استضافة.

تصحيح لقراءة سابقة: `render.yaml` في **فرع الإطلاق الحالي** يحدد `starter` وقرصًا عند `/var/data/khadamati` وفرع `release/production-readiness` مع `autoDeployTrigger: off`. وصف إعداد `main` المجاني لا ينطبق على هذا الملف. وجود ملف الإعداد لا يثبت أن Render طبّقه بالفعل.

## مسار الإطلاق التالي

1. ربط Render وتأكيد أن النسخة المنشورة والقرص والنسخ الاحتياطية سليمة، وتجهيز بيئة اختبار منفصلة.
2. تأكيد حسابَي المطور والجهة المالكة والمعرّف، واعتماد سياسة الخصوصية والحذف والدعم وطريقة الاشتراكات.
3. إكمال إشعارات الهاتف والمشتريات الرقمية إذا ستتاح في الإصدار الأول، واختبارها مع جلسات الدخول والملفات على أجهزة فعلية.
4. توقيع نسخة Android وiOS من الالتزام المختبر، ورفعها للاختبار الداخلي وTestFlight.
5. استكمال قائمة المتجر والإفصاحات والتصنيف العمري وحسابات المراجعة، ثم إرسال الإصدار للمراجعة. قرار القبول وتوقيت النشر بيد المتجرين.

## التحقق

- الكود المرشح النهائي: `7057e2ea08e036ee53bcd4719f86b0de68f3b473`.
- 178 اختبار Python محلي ناجح، و12 فحص أمان API، و30 فحص API معزول.
- 7 اختبارات ربط هاتف ناجحة، وتحقق الترجمات الخمس بـ 4919 صفًا.
- `npm audit --prefix mobile --audit-level=high`: صفر ثغرات معروفة بعد تحديث sharp وتثبيت uuid المتوافق.
- أثبت اختبار الحذف الخطأ قبل الإصلاح برسالة `Deleted account retained email`، ثم نجح بعده، بما يشمل رفض الرمز الخاطئ وإبطال الجلسة.
- لم يجر اختبار مخزن كوكيز iOS/Android أو أذونات النظام أو APNs/FCM أو كاميرا/ميكروفون جهاز فعلي. اختبارات الواجهة تستخدم استجابات API وإضافات هاتف معزولة؛ اختبارات الخادم تستخدم خادم Python وقاعدة بيانات مؤقتة فعليين.
- نجح بناء الهاتف النهائي: [CI #34437899003](https://github.com/LLLX6/Khadamati/actions/runs/34437899003)، ويتضمن Android وiOS واختبار ربط الواجهة واللغات الخمس.
- نجحت [بوابة الجودة #34437899019](https://github.com/LLLX6/Khadamati/actions/runs/34437899019) كاملة: الخادم والأمان والواجهة على المقاسات 320×740 و375×812 و390×844 و430×932 و1280×800، واللغات الخمس وفحص الأداء.
- سجل اختبار API المعزول p95 قدره 61.24 مللي ثانية دون أخطاء، وسجل اختبار واجهة الويب جاهزية التفاعل بعد 1753 مللي ثانية. هذه قياسات بيئة الاختبار وليست قياسات خادم الإنتاج أو جهاز فعلي.

## التسليم والتراجع

- العمل مرفوع على فرع مستقل في PR #11، المبني على إصلاحات PR #10. لم يدمج في main أو فرع الإنتاج، ولم يجر رفع إلى TestFlight أو Play Console.
- ملفات التوقيع والشهادات وكلمات المرور غير موجودة في المستودع. لم يشتر أي حساب أو خدمة.
- يمكن التراجع عن التجربة بإزالة APK الداخلي. لم تنفذ أي ترحيلات أو عمليات حذف على الإنتاج، ولا حاجة لاسترجاع بيانات الإنتاج بسبب هذا العمل.
- بعد توقيع إصدار متجر، يجب زيادة رقم البناء عند كل رفع لاحق. يلزم حفظ مفتاح رفع Android ومواد توقيع Apple في حسابات الجهة المالكة وإدارة أسرار آمنة.
